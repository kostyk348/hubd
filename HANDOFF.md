**Что это.** Минимальный хаб подписок + сканер источников. Собран из двух питчей свежего дайджеста музея
(https://kostyk348.github.io/lost-tech-museum/digests/rfc-graveyard/):

- `ipmulticast` — «адрес группы вместо списка получателей»: издатель публикует в тему и не знает подписчиков;
- `pubsubhubbub` — pubsub поверх HTTP (идея, которая стала WebSub, но так и не стала слоем инфраструктуры);
- `rsvp` / `atmip` — «контракт доставки»: подписка — аренда, а неподтверждённые доставки заканчиваются
  честным отказом (503 + причина), а не тихой потерей сообщения.

**Где:** `/home/lain/.hermes/profiles/libraressa/workspace/hubd` (это твоя рабочая папка приложений).
Музей (только чтение): `/home/lain/.hermes/profiles/libraressa/workspace/lost-tech-museum`.

## Состояние: работает, проверено запуском

```
$ python3 -m unittest discover -s tests -t .      →  Ran 20 tests ... OK
$ python3 -m hubd demo --workdir /tmp/hubd-demo   →  подписка HTTP 202, две доставки с подписью, итог 2/2
$ python3 -m hubd check --watchlist watchlist.example.json --state /tmp/scan.json
    200 без изменений  https://www.rfc-editor.org/rfc/rfc3170.txt
    304 без изменений  (второй обход: ETag работает, повторной загрузки нет)
```

Что уже реализовано: рукопожатие подписки с проверкой намерения (challenge), аренда с истечением и
продлением, доставка POST с `X-Hub-Signature: sha256=…` (HMAC секрета), журнал в JSONL,
`/healthz`, `/subscriptions`, `/journal`, сканер с условным GET (`If-None-Match`/`If-Modified-Since`),
дедупликация по sha256, вежливая пауза между запросами к одному хосту, подавление «болтливых» источников
без валидаторов (пока в списке наблюдения не сказано `"allow_volatile": true`).

## Правила, которые нельзя нарушать

- Python stdlib, ноль зависимостей: `pip install` в этом репозитории не должно появиться без причины.
- Перед каждым коммитом `python3 -m unittest discover -s tests -t .` — зелёные тесты.
- «Работает» подтверждается выводом команды, а не описанием; не работает — пишем, что не работает.
- В музей (`data/`, `stacks/`) не пишешь: там свои писатели. Ссылаешься на записи по `id`.
- Коммиты: `<область>: <что изменилось>` (например `hub: очередь повторных доставок`).
